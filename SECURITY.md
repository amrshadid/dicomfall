# Security

DICOMFall is a static site: everything runs in your browser, with no backend and no
account. The Linux machine the game boots runs inside your browser tab and cannot reach
your computer's files or network beyond the site itself.

## Reporting a problem

If you find a security problem, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/amrshadid/dicomfall/security/advisories/new)
rather than in a public issue. Say what you found, how to reproduce it, and what it could
affect. You'll get a reply as soon as possible.

Problems in go-dicom itself belong to
[go-dicom's own tracker](https://github.com/amrshadid/go-dicom/security).

## Supported versions

Only the version live at [dicomfall.shadid.dev](https://dicomfall.shadid.dev), built from
`main`, is supported.
